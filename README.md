# open ToDo — إدارة حقيقية للمهام

تطبيق ثنائي اللغة (العربية RTL / الإنجليزية LTR) بخط **ثمانية سانس**، مبني بـ
**Next.js 16 + React 19 + TypeScript** و**Prisma** و**Auth.js**. كل زر يعمل، وكل
رقم محسوب من بيانات حقيقية، وكل شيء محفوظ — لا مهام وهمية ولا إحصاءات مزيفة.

## المزايا (حقيقية ومحفوظة)

- **اللغة** — زر تبديل في الأعلى (EN / ع) يبدّل العربية والإنجليزية فورًا:
  الاتجاه (RTL/LTR)، كل النصوص، التواريخ والأرقام، وحتى رسائل الخطأ وسجل
  النشاط — حسب لغة كل مستخدم (تُحفظ في كوكي `locale`). والإعدادات فيها خيار لغة أيضًا.
- **الحسابات** — إنشاء حساب / دخول / خروج مع تشفير bcrypt وجلسات server-side.
  عند التسجيل تُنشئ **اسم مستخدم** فريدًا، والدخول يقبل **البريد أو اسم
  المستخدم**. كل استعلام مرتبط بالمستخدم الحالي.
- **المهام** — إضافة سريعة (اكتب واضغط Enter)، محرر كامل، إكمال/إعادة فتح
  (تعود للحالة السابقة)، حذف بتأكيد + تراجع حقيقي.
- **التنظيم** — مشاريع (اسم، وصف، أيقونة، لون، تقدّم حقيقي)، وسوم، أولويات،
  تواريخ استحقاق، ملاحظات.
- **الصفحات** — لوحة التحكم، الوارد، اليوم، القادمة (مجموعات من البيانات)،
  المكتملة (بحث / تصفية / استعادة / حذف)، وصفحات المشاريع.
- **البحث والفلاتر** — في العناوين والأوصاف والوسوم والمشاريع؛ تصفية بالحالة
  والأولوية والمشروع والوسم والتاريخ؛ ترتيب يدوي وبتاريخ الاستحقاق والأولوية
  والإنشاء والتحديث. كلها في الخادم.
- **الترتيب اليدوي** — سحب وإفلات وأزرار أسهم، وكلاهما محفوظ.
- **تواريخ صحيحة** — اليوم والمتأخر والقادم حسب منطقتك الزمنية (من الإعدادات).
- **المظهر** — فاتح / داكن / النظام، محفوظ.
- **متجاوب** — شريط جانبي لسطح المكتب، ودرج تنقل للجوال.
- **الاختصارات** — `N` مهمة جديدة، `/` بحث، `Esc` إغلاق (لا تتعارض مع الكتابة).
- **الحالات** — شاشات فارغة حقيقية، هياكل تحميل، معالجة أخطاء، تنبيهات عند
  النجاح فقط، وتحديث متفائل مع التراجع عند الفشل.
- **الإعدادات** — اللغة، الملف الشخصي، المنطقة الزمنية، المظهر، تغيير كلمة
  المرور، حذف الحساب (يحذف كل البيانات بعد كلمة المرور والتأكيد).

## التشغيل

```bash
npm install
npm run db:migrate   # تطبيق migrations على قاعدة Supabase
npm run dev          # http://localhost:3000
```

أنشئ حسابًا من `/register` — لا يوجد مستخدمون تجريبيون ولا بيانات مزروعة.

### الأوامر

| الأمر                       | الوظيفة                                  |

| `npm run dev`               | خادم التطوير                             |

## قاعدة البيانات (Supabase — الإعداد الحالي)

قيم الاتصال في `.env` (مستثنى من git ولا يُرفع أبدًا):

- `DATABASE_URL` — التشغيل عبر Supabase pooler بوضع transaction
  (المنفذ `6543` مع `?pgbouncer=true`). رمز `@` في كلمة المرور يُرمّز `%40`.
- `DIRECT_URL` — الـ migrations عبر الـ pooler بوضع session
  (المنفذ `5432` على نفس مضيف الـ pooler)، لأن الـ migrations تحتاج DDL إجرائيًا.

## الخط

يستخدم التطبيق خط **ثمانية سانس** (من تصميم وملكية ثمانية) عبر الحزمة
`@dawod/thmanyah-font-web` — تُحمّل ملفات الخط من CDN مع `font-display: swap`
وخطوط النظام كاحتياطي. راجع `font.thmanyah.com/licenses` لشروط الاستخدام.

## البنية

```text
app/
  page.tsx                    # تحويل حسب الجلسة (لا صفحة هبوط)
  login/  register/           # دخول Auth.js
  (app)/                      # مساحة العمل (محمية في الخادم)
    dashboard/ inbox/ today/ upcoming/ completed/
    search/ settings/
    projects/  projects/[id]/
  api/auth/[...nextauth]/     # معالج Auth.js
components/
  locale-provider.tsx  # سياق اللغة + الثيم + التنبيهات
  layout/   # الهيكل، الشريط الجانبي (عدّادات حقيقية)، الأعلى (بحث، لغة، مظهر، حساب)
  tasks/    # عناصر المهام، الإضافة السريعة، المحرر، لوحة التفاصيل، الفلاتر
  projects/ # نموذج المشروع، العرض، إدارة الوسوم، إجراءات المشروع
  settings/ # نماذج اللغة والملف الشخصي والمظهر وكلمة المرور والحذف
  ui/       # أزرار، حقول، نوافذ، تأكيد، شارات، حالات فارغة، هياكل
features/
  auth/      # إنشاء الحساب وتسجيل الخروج
  tasks/     # عمليات المهام والترتيب والاستعادة والقراءات
  projects/  # عمليات المشاريع والوسوم
  settings/  # الملف الشخصي وكلمة المرور وحذف الحساب
lib/
  i18n/      # قواميس ar/en + قراءة اللغة من الكوكي + action الحفظ
  validations.ts  # مصنع تحقق Zod حسب اللغة
  dates.ts        # تواريخ بتوقيت المستخدم ولغته
prisma/      # الـ schema والـ migrations
```

### قواعد مطبّقة في الكود

- **مصادقة في الخادم دائمًا** — تخطيط `(app)` يحوّل المجهولين؛ كل Action
  يتحقق من المستخدم وكل قراءة تُصفّى بـ `userId`.
- **تحقق في الخادم** — كل المدخلات تُتحقق بـ Zod برسائل بلغة المستخدم.
- **لا واجهة ميتة** — الفلتر أو الزر موجود فقط إذا استعلم أو غيّر بيانات حقيقية.

## اختصارات لوحة المفاتيح
